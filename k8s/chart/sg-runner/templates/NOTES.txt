sg-runner {{ .Chart.Version }} installed as StatefulSet {{ $ns }}/{{ $sts }} ({{ if .Values.runner.nativeSteps.enabled }}native steps{{ else }}size: {{ .Values.runner.size }}{{ end }}).

Runner group: {{ .Values.sg.organization }}/{{ .Values.sg.runnerGroup }}. Each replica registers one runner on its
first start.

Runner pods are privileged (nested Docker). Where Pod Security is enforced, the
namespace needs:

  kubectl label namespace {{ $ns }} pod-security.kubernetes.io/enforce=privileged

Runners:
  kubectl -n {{ $ns }} get statefulset,pods -l app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component=runner

Parked runners are state PVCs without a pod (still registered in SG, shown as
DRAINING and disconnected):
  kubectl -n {{ $ns }} get pvc | grep '^state-{{ $sts }}-'
{{- if .Values.scaler.enabled }}

The scaler owns the replica count ({{ .Values.scaler.min }}..{{ .Values.scaler.max }}). Watch its decisions:
  kubectl -n {{ $ns }} logs -f deploy/{{ include "sg-runner.scalerName" . }}
{{- if .Values.scaler.leaderElection.enabled }}
With several scaler replicas only the lease holder decides:
  kubectl -n {{ $ns }} get lease {{ include "sg-runner.runnerName" . }}-scaler
{{- end }}

Don't `kubectl scale` the StatefulSet by hand; the scaler overrides it.
{{- else }}

Scaler disabled: the StatefulSet runs {{ .Values.runner.replicas }} replica(s). Scaling down parks runners,
scaling up wakes them:
  kubectl -n {{ $ns }} scale statefulset {{ $sts }} --replicas=N
{{- end }}

{{- if .Values.uninstall.deregister }}
`helm uninstall` deregisters every runner and deletes their PVCs; it waits for
running workflows, so pass a --timeout that covers them:
  helm -n {{ $ns }} uninstall {{ .Release.Name }} --timeout 30m
{{- else }}
uninstall.deregister=false: `helm uninstall` keeps the PVCs, and runners stay
registered in SG as parked.
{{- end }}
{{- if .Values.runner.nativeSteps.enabled }}

Native steps (experimental): one runner per node, advertising {{ .Values.runner.nativeSteps.advertise.cpu }} CPU / {{ .Values.runner.nativeSteps.advertise.memory }}.
Each workflow step runs as a pod on its runner's node:
  kubectl -n {{ $ns }} get pods -l app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component=step
  kubectl -n {{ $ns }} logs -f <step pod>
Only while a step runs: a finished step pod is deleted once its run controller
has the result (the output is in SG).
The steps broker in each runner pod creates them:
  kubectl -n {{ $ns }} logs -f {{ $sts }}-0 -c steps
{{- end }}
{{- if .Values.networkPolicy.enabled }}

NetworkPolicy {{ $sts }} only takes effect with a CNI that enforces it.
{{- if .Values.runner.nativeSteps.enabled }}
It blocks the Kubernetes API too, which the steps broker needs: allow the API
server's endpoint (`kubectl get endpoints kubernetes`) in
networkPolicy.extraEgress. That opens it to everything in the runner pod.
{{- end }}
{{- end }}
